GazeFace は、Web カメラだけで Windows を操作するための無料・オープンソースのアプリです。頭の動きでマウスポインタを動かし、表情（口を開ける、眉を上げる、目を閉じる など）でクリックやキー入力を行います。視線を使って画面上の離れた場所へ一気に移動したり、画面いっぱいのタイルを見つめて機能を呼び出したりすることもできます。

手や腕を使ったマウス・キーボード操作が難しい方（四肢麻痺、頸髄損傷、ALS、筋ジストロフィーなど）が、顔だけで、介助なしでパソコンを使えることを目指しています。

## 主な機能

- **ヘッドトラッキング**: 頭の動きでポインタを移動。上下左右の速度を個別に設定
- **表情ジェスチャー**: 23 種類の表情を、左・右・中クリック、ダブルクリック、押しっぱなし（ドラッグ）、キー入力やショートカットに割り当て
- **視線ジャンプ**: 見ている場所の近くへポインタを一気に移動。近くのリンクやボタンに吸着
- **視線移動**: 画面に出る矢印を見つめた方向へポインタを滑らせる
- **首振りホイールモード**: 首振りでマウスホイールを回してスクロール
- **視線ランチャー**: 画面いっぱいのアイコンを見つめて、キー操作・マクロ・アプリ起動などを実行
- **視線タスクスイッチャー / 視線クリップボード履歴**: ウィンドウの切り替えや、保存したテキストの貼り付けを視線で
- **サインイン画面・UAC 画面での利用**（完全版）: Windows の支援技術として登録し、サインイン前や管理者の確認画面でも操作
- **プロファイル**: 人や場面ごとに設定を切り替え
- **自動復旧・自動更新**: 不調時は自動で立て直し、新しいバージョンは顔の操作だけで更新

## 動作環境

最低:

- Windows 10 / 11（64 ビット）
- CPU: 4 コア（Intel Core i5 第 8 世代 / AMD Ryzen 5 3000 シリーズ以上）
- メモリ: 8 GB
- ストレージ: 空き 1 GB
- GPU: Direct3D 11 に対応した内蔵 GPU（Intel UHD 620 / AMD Radeon Vega 以上）
- Web カメラ: 720p、30 fps

推奨:

- CPU: 6 コア以上
- メモリ: 16 GB
- 使う場所の明るさでよく映る Web カメラ

顔の検出は CPU で行い、CPU の 1 スレッド分ほどを使い続けます。GPU は画面に重ねて表示する部分の描画にだけ使います。

## インストール

[Releases](../../releases) から `GazeFace-Setup-<バージョン>.exe` をダウンロードして実行します。常に最新版を指す直リンクは [GazeFace-Setup.exe](https://github.com/dNv72DgH/GazeFace/releases/latest/download/GazeFace-Setup.exe) です。`C:\Program Files\GazeFace` にインストールされ、スタートメニューから起動できます。初回起動時に視線キャリブレーションの案内が表示されます。

インストーラーの途中で **完全版** と **通常版** を選びます（次の節を参照）。完全版を選ぶと、続けて「サインイン画面で軽量版を起動する」「サインイン後に起動する」を選べます。

インストーラー自体はコード署名していないため、Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で続けてください。

「実行」の選択肢が出ずにブロックされる場合は、スマート アプリ コントロールがオンになっている可能性があります。「Windows セキュリティ」→「アプリとブラウザーの制御」→「スマート アプリ コントロールの設定」で確認できます。オフにすると GazeFace のような署名のないアプリを実行できるようになりますが、一度オフにすると Windows を入れ直すまでオンに戻せません。S モードの Windows には GazeFace をインストールできません。

### 更新

GazeFace は起動中に 1 日 1 回新しいバージョンを確認し、見つかるとウィンドウ内でお知らせします。「今すぐ更新」を選ぶまでは何もインストールしません。選ぶと確認画面なしで更新し、GazeFace が自動で再起動します。更新は管理者の確認画面（UAC）を出さずに行うため、顔の操作だけで完了します（インストール時に登録する更新専用のタスクが、GitHub のリリースからダウンロードしたファイルの SHA-256 を照合してから実行します）。お知らせが不要な場合は「詳細設定」→「更新」→「更新を通知する」をオフにします。

### アンインストール

「設定」→「アプリ」から行います。完全版で作った証明書と秘密鍵、専用マウスドライバー、更新用タスクもあわせて削除されます。設定とログ（`%LOCALAPPDATA%\GazeFace`）は残ります。

## 完全版と通常版

**完全版**（インストーラーの初期選択）

- 管理者として動くウィンドウ（タスク マネージャー、インストーラーなど）も操作できます。
- ユーザー アカウント制御（UAC）の確認画面、サインイン画面、ロック画面でも操作できます（Windows の支援技術として登録し、これらの画面では専用の軽量版が起動します）。
- サインイン後に Windows がマウスポインタを隠したままにしてしまう現象を、専用の仮想マウスドライバーで解除します。
- ほぼすべての操作を介助なしで行えます。
- そのために、この PC だけで通用する証明書を作り、GazeFace に署名します（次の節）。

**通常版**

- 通常の権限で動きます。証明書の登録、署名、ドライバーのインストールは行いません。
- 管理者として動くウィンドウ、UAC の確認画面、サインイン画面・ロック画面は操作できません。これらが前面に出るとポインタやクリックが効かなくなるため、家族や介助者の手助けが必要になります。
- Windows のスタートアップ（サインイン時・サインイン後の起動）は使えません。

どちらの版かは「詳細設定」→「GazeFaceについて」で確認できます（Full Edition / Standard Edition）。インストーラーを再実行すれば、いつでも版を切り替えられます。通常版に切り替えると、完全版の証明書・秘密鍵・ドライバーは削除されます。

### 仮想マウスドライバーの目的

Windows は、サインインした直後などに、マウスが実際に動かされるまでマウスポインタを画面から隠したままにすることがあります。このとき GazeFace が通常の方法（Windows の `SendInput`）で送るマウス操作は「マウスが動いた」とはみなされず、ポインタは隠れたままです。手でマウスに触れれば表示されますが、顔だけで操作している人にはそれができず、ポインタの見えない状態から抜け出せなくなります。

完全版でインストールされる仮想マウスドライバー（GazeFace Virtual Mouse）は、Windows からは本物のマウスとして見えます。GazeFace はポインタが隠されていることを検知したときだけ、この仮想マウスからごく小さな動きを送ってポインタを表示させます。

- 使い道はこれだけです。ポインタの移動、クリック、ホイールなどの操作はすべて通常の方法で行い、仮想マウスは使いません。
- 1 回の動作は「1 ピクセル横へ動かして元の位置に戻す」だけで、ポインタの位置は変わりません。同じ「隠れた状態」の間に送るのは 1 回だけです。
- ドライバーにはボタンを押す機能自体がなく、クリックはできません。
- ユーザーモードドライバー（UMDF）で、Windows の中核（カーネル）では動きません。万一不具合があっても、Windows 全体を巻き込みにくい作りです。カーネルドライバーにはさらに高額な証明書と Microsoft の審査が必要ですが、ユーザーモードドライバーは完全版の証明書で署名できます。
- ドライバーが入っていない場合（通常版など）は何もせず、それ以外の動作は変わりません。

## 完全版の自動署名について

### なぜ署名が必要か

Windows は、より高い権限で動くウィンドウ（管理者として実行中のアプリなど）へのマウス・キーボード入力を、通常のアプリからは受け付けません。これを越えて操作できるのは、**UIAccess** という支援技術専用の特別な権限を持つアプリだけです。Windows は次の条件をすべて満たす場合にだけ UIAccess を認めます。

1. 実行ファイルが UIAccess を要求している（GazeFace では `GazeFace_UI.exe`）
2. その実行ファイルが、**PC が信頼する証明書でデジタル署名されている**
3. `Program Files` など保護された場所にインストールされている

また、サインイン画面や UAC 画面で支援技術として起動するためにも、署名済みの `GazeFace_UI.exe` が必要です。専用の仮想マウスドライバーも、署名がなければ Windows がインストールを拒否します。

### 署名済みで配布できない理由

本来は、認証局から購入したコード署名証明書で開発者が署名して配布するのが一般的です。しかし、

- コード署名証明書は毎年数万円以上の費用がかかり、ドライバー向けにはさらに高額な証明書が必要です。
- GazeFace は無料のソフトウェアで、収益はありません。
- 顔だけでパソコンを操作したいという需要は確実にある一方、その人数はとても少ないと予想され、高額な証明書の費用を負担し続けることは現状難しいと判断しました。

そこで完全版では、インストーラーが **その PC の中だけで通用する証明書** を作り、その PC 上で署名する方式を取っています。

### インストーラーが自動で行うこと

完全版を選ぶと、インストール後に管理者権限の PowerShell スクリプト（`installer/custom/full_edition.ps1`）が次の処理を行います。処理の様子はコンソール画面に表示されます。

1. 「`CN=GazeFace Local Signing`」という名前のコード署名用の自己署名証明書を作ります（有効期限 10 年）。
2. 秘密鍵は、その PC の「ローカル コンピューター」の証明書ストアに **取り出し不可（NonExportable）** で保存します。読めるのは管理者と SYSTEM だけです。
3. 証明書（公開部分）を「信頼されたルート証明機関」と「信頼された発行元」に登録します。
4. `GazeFace_UI.exe` と、仮想マウスドライバーのカタログファイル（`driver\gfmouse.cat`）に署名し、署名が有効か確認します。
5. 仮想マウスドライバーをインストールします。
6. 2 回目以降（更新時）は、条件を満たす限り同じ証明書を使い回します。期限が 30 日以内に迫った場合や、証明書・鍵が壊れている場合だけ作り直します。

秘密鍵を PC に残す理由: 一部の Windows では、デスクトップ アプリを署名者で見分けてカメラの使用許可を管理します。更新のたびに新しい証明書で署名すると「別のアプリ」とみなされ、カメラの許可を聞き直されます。許可するまでカメラが使えず、顔の操作では許可ボタンを押せないため、同じ鍵で署名し続ける必要があります。

アンインストール時と通常版への切り替え時には、この証明書（ルート・信頼された発行元・秘密鍵付きの本体）をすべて削除します。

署名の処理は公開しているスクリプトだけで行い、インストーラーの外から何かをダウンロードすることはありません。内容は [installer/custom/full_edition.ps1](installer/custom/full_edition.ps1) と [installer/GazeFace.iss](installer/GazeFace.iss) で確認できます。

### リスク

完全版を選ぶ前に、次の点を理解してください。

- **PC の信頼の仕組みに手を加えます。** 「信頼されたルート証明機関」に証明書を追加することは、その証明書で署名されたプログラムを PC が信頼するということです。
- **秘密鍵が PC に残ります。** 取り出し不可で、管理者と SYSTEM しか使えませんが、管理者権限を奪ったマルウェアはこの鍵を使って自分自身に署名し、この PC で「信頼されたプログラム」や「確認なしで入るドライバー」として振る舞える可能性があります（ただし、管理者権限を奪われた時点で PC はすでに乗っ取られた状態です）。
- **UIAccess を持つアプリは、管理者として動くウィンドウにも入力を送れます。** GazeFace 自身がその権限で動きます。
- **偽のインストーラーに注意してください。** 改ざんされたインストーラーは、同じ仕組みで不正なプログラムを信頼させることができます。インストーラーは必ず [公式のリリース](../../releases) から入手してください。

これらを理解したうえで、自己責任で選んでください。不安がある場合は、通常版を使うか、次の手動署名を選べます。

## 手動で署名する方法

自動署名に不安がある方は、**通常版** をインストールしてから、自分で `GazeFace_UI.exe` に署名できます。自分で証明書の名前や扱いを決められ、署名後に秘密鍵を削除して PC に残さないこともできます。

GazeFace は、署名済みで信頼された `GazeFace_UI.exe` が `Program Files` にあれば、次回の起動から自動でそちらを使います（「詳細設定」→「スタートアップ」も使えるようになります）。

### 手順

1. インストーラーで **通常版** を選んでインストールします。
2. GazeFace を終了します（実行中のファイルには署名できません）。
3. スタートメニューで「PowerShell」を右クリック →「管理者として実行」を選び、次を実行します。

```powershell
# 1. コード署名用の自己署名証明書を作る（名前は自由。ただし "CN=GazeFace Local Signing" 以外にする）
$name = 'CN=GazeFace Manual Signing'
$cert = New-SelfSignedCertificate -Subject $name -Type CodeSigningCert `
  -CertStoreLocation Cert:\LocalMachine\My -KeyExportPolicy NonExportable `
  -NotAfter (Get-Date).AddYears(10)

# 2. 証明書（公開部分）をこの PC の「信頼されたルート証明機関」に登録する
$cer = Join-Path $env:TEMP 'gazeface_manual.cer'
Export-Certificate -Cert $cert -FilePath $cer | Out-Null
Import-Certificate -FilePath $cer -CertStoreLocation Cert:\LocalMachine\Root | Out-Null

# 3. GazeFace_UI.exe に署名して、状態が Valid になったことを確認する
$exe = 'C:\Program Files\GazeFace\GazeFace_UI.exe'
Set-AuthenticodeSignature -FilePath $exe -Certificate $cert -HashAlgorithm SHA256
(Get-AuthenticodeSignature $exe).Status
```

4. 秘密鍵を PC に残したくない場合は、続けて次を実行します（ルートに登録した公開部分は残るため、署名済みの `GazeFace_UI.exe` は引き続き信頼されます）。

```powershell
Remove-Item -LiteralPath ('Cert:\LocalMachine\My\' + $cert.Thumbprint) -DeleteKey
Remove-Item $cer
```

5. GazeFace を起動します。「詳細設定」→「GazeFaceについて」が **Full Edition** になっていれば成功です。

証明書の名前は `CN=GazeFace Local Signing` 以外にしてください。この名前の証明書は、通常版のインストール・更新時にインストーラーが削除します。

### 手動署名の注意点

- **更新のたびに署名し直す必要があります。** 更新で `GazeFace_UI.exe` が署名のないファイルに置き換わるため、署名し直すまでは通常版として動きます（顔の操作は通常どおり使えます）。
- 秘密鍵を削除した場合、次回は新しい証明書を作って署名することになります。署名者が変わるため、一部の Windows ではカメラの使用許可を聞き直されます。許可は顔の操作では押せないため、介助者がいるときに行ってください。
- サインイン画面・UAC 画面での起動は、署名後に「詳細設定」→「スタートアップ」で設定します。
- 仮想マウスドライバー（サインイン後にポインタが消える現象の解除用）は、手動署名では入りません。必要な場合は、手順 4 で秘密鍵を削除する **前に**、同じ PowerShell で次を実行します。

```powershell
Import-Certificate -FilePath $cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher | Out-Null
Set-AuthenticodeSignature -FilePath 'C:\Program Files\GazeFace\driver\gfmouse.cat' -Certificate $cert -HashAlgorithm SHA256
& 'C:\Program Files\GazeFace\driver\gfmouse_setup.ps1'
```

  スクリプトの実行がブロックされる場合は、先に `Set-ExecutionPolicy -Scope Process Bypass` を実行してください（この PowerShell ウィンドウの中だけ有効です）。

### 手動で入れた証明書を削除する

```powershell
$name = 'CN=GazeFace Manual Signing'
foreach ($s in 'Root', 'TrustedPublisher') {
  Get-ChildItem "Cert:\LocalMachine\$s" | Where-Object Subject -eq $name | Remove-Item
}
# 秘密鍵を残している場合のみ（鍵ごと削除）
Get-ChildItem Cert:\LocalMachine\My | Where-Object Subject -eq $name |
  ForEach-Object { Remove-Item -LiteralPath ('Cert:\LocalMachine\My\' + $_.Thumbprint) -DeleteKey }
```

ドライバーを入れた場合は、`powershell -ExecutionPolicy Bypass -File "C:\Program Files\GazeFace\driver\gfmouse_setup.ps1" -Remove` で削除できます。

## 使い方の流れ

1. Web カメラを接続し、顔が正面から映る位置に置きます。
2. GazeFace を起動します。初回は視線キャリブレーションが始まるので、画面に出る緑の点を順番に見つめます。
3. 左下の **「顔操作」** をオンにすると、頭の動きでポインタが動き、表情でクリックできるようになります。
4. 「マウス」「キーボード」ページで、使う機能に表情を割り当て、反応の強さを調整します。
5. 必要に応じて「拡張機能」でランチャーなどを設定します。

## 機能マニュアル

画面左のメニューは「ホーム」「カーソル」「マウス」「キーボード」「拡張機能」「ブックマーク」「詳細設定」と、「視線キャリブレーション」「再起動」で構成されています。

### 共通の表示（左側）

- **カメラの映像とステータス**: 顔の検出状態（有効・準備中・検出中・無効・エラー・復旧中など）を表示します。
- **顔操作**: 顔による操作全体のオン・オフ。オフの間はポインタ移動もジェスチャーも働きません。
- **サブモニター**: 割り当てたジェスチャーの現在値を棒グラフで表示する、常に最前面の小さなウィンドウを表示します。表情の出し加減を確かめながら作業できます。
- **再起動**: アプリを再起動します。

### ホーム

- **カメラを選択**: 使う Web カメラを選び、映像を確認します。
- **プロファイル**: 設定のまとまりを人や場面ごとに作り、クリックで切り替えます。「プロファイルを管理」で追加・名前の変更・削除ができます。割り当て・速度・感度などはプロファイルごとに保存されます。

### カーソル（ヘッドトラッキング）

- **上方向 / 下方向 / 右方向 / 左方向**: 頭の動きに対するポインタの速さを方向ごとに設定します（0〜1000）。0 にするとその方向へは動きません。速くしすぎると操作できなくなるため、少しずつ調整してください。
- **ポインタ スムージング**: 大きくすると滑らかに動きますが、その分遅れます。
- **ホールド判定遅延 (ms)**: クリックした後、指定時間ジェスチャーを続けると押しっぱなし（ドラッグ）に変わります。

### マウス

機能ごとに、割り当てる表情、反応のしきい値（スライダー。バーに現在の値が表示されます）、「表情オプション」「機能オプション」、ブックマーク（☆）を設定します。

割り当てられる機能:

- **左クリック / 右クリック / 中クリック / ダブルクリック**
- **一時停止 / 再開**: 顔操作を一時停止・再開します。
- **視線ジャンプ**: 見ている場所の周辺へポインタを移動します（後述）。
- **視線移動**: 矢印を見つめた方向へポインタを滑らせます（後述）。
- **首振りホイールモード 上下左右 / 左右上下**: 首振りでホイールを回します（後述）。
- **視線ランチャー / 視線クリップボード履歴 / 視線タスクスイッチャー**: 拡張機能を開きます。
- **カーソルを中央へ戻す**
- **モニタを切り替える**: 複数モニターの間でポインタを移動します。

#### 視線ジャンプ

現在見ている場所の周辺にポインタを移動します。Web カメラの視線検出は精度に限界があるため大まかな移動になりますが、視線移動やヘッドトラッキングと組み合わせると、細かな移動まで素早く行えます。事前に視線キャリブレーションが必要です。

機能オプション:

- **待機時間 (ms)**: ジェスチャーを保持してから、ジャンプするまでの時間。この間ポインタは固定されます。
- **リンク吸着**（初期値オン）: ジャンプ先の近くにボタンやリンクがあれば、その上に移動します。**範囲 (px)** で探す範囲を設定します。アプリやサイトによっては働かない、または誤認識することがあります。
- **視覚的に通知**（初期値オフ）: ボタンやリンクに吸着したとき、着地のアニメーションに色を付けて知らせます。
- **ジャンプ直後に視線移動を起動する**: ジャンプした直後に視線移動の矢印を出し、続けて目的地まで滑らせます（オン推奨）。
- **顔操作がオフでも視線ジャンプを許可**

#### 視線移動

画面に 8 方向の矢印と中央のターゲットを表示し、見つめた方向の矢印を強調します。表示時間が過ぎると、その方向へポインタがまっすぐ動きます（中央を見ているとキャンセル）。移動中にもう一度視線移動のジェスチャーで停止、その他のジェスチャーでそれに割り当てられた機能を即実行します。

機能オプション: **矢印の表示時間 (ms)**、**移動速度 (px/秒)**。

#### 首振りホイールモード

ポインタを動かす代わりに、頭の動きでマウスホイールを回します。開始した時の頭の位置が起点で、起点から離れている間はホイールを回し続け、離れるほど速く回ります。モード中はポインタの横にアイコンが表示されます。もう一度同じジェスチャーで終了、その他のジェスチャーで終了してその機能を即実行します。顔操作をオフにしても終了します。

- **上下左右**: 上下の首振りで縦スクロール、左右の首振りで横スクロール
- **左右上下**: 左右の首振りで縦スクロール、上下の首振りで横スクロール

機能オプション（上下・左右の首振りそれぞれに設定）:

- **無効ストローク範囲 (0.1%単位)**: 起点からこの範囲内の動きではスクロールしません（0 で遊びなし）。
- **スクロール量**: 1 回に送るホイール量（120 で 1 ノッチ）。
- **回転速度 (10秒あたりの回数)**: 無効ストローク範囲を出た直後の、最も遅い回転の速さ。
- **感度**: 起点から離れるほど速くなる度合い（0 で常に同じ速さ）。
- **反転 / 無効**

#### 表情オプション（ジェスチャーごと）

表情に紐づく設定で、割り当てる機能を変えても引き継がれます。

- **感度 (ジェスチャ別)**: 全体の感度に上乗せでかかる倍率（1.0 で変更なし）。
- **保持時間 (ms)**: しきい値を超え続けてから反応するまでの時間。照明などで短いノイズのような入力が繰り返される場合、200 ms 程度にすると抑えられます。
- **反応カーブ**: リニア / 弱→強（弱い表情ではほとんど反応せず、強いと大きく反応）/ 強→弱（弱い表情でもはじめから大きく反応）。
- **スライダ上限値 / 下限値**: スライダの動きが小さくて見にくい時や、反応カーブを「強→弱」にした時に調整します。
- **ジェスチャー時ポインタ停止**: 表情を作る動きでポインタがずれないよう、値が急に上がった時にポインタを止めます。**停止感度** と **まばたき・不随意運動を無視**（猶予時間）を設定できます。安全のため 10 秒で自動解除されます。
- **同時入力禁止**: この表情が動いている間、優先順位の低い他の表情を無視します（**検出感度**、**優先順位**）。
- **強い反応時に無効化**: 不意に笑ったときなどの暴発を抑えます（**検出感度**、**無効時間（秒）**）。
- **チャタリング防止**: クリックなどが意図せず連続で入力されるのを防ぎます。何かの入力があってから **間隔 (ms)** の間、この表情のクリックやキー入力を無視します（オン推奨）。

### キーボード

「+ 追加」で、表情とキーの組み合わせを登録します。修飾キー（Ctrl・Shift・Alt・Win）にチェックを入れてメインのキーを押すと、ショートカット（例: Ctrl+C）も割り当てられます。反応のしきい値と表情オプションはマウスと同じです。

### 拡張機能

画面いっぱいのタイル（グリッド）を視線で選ぶツールです。表情で決定、戻る、終了などを行います。ツールを開いている間だけ使う表情の割り当て（**表情割り当て**）は、メインの割り当てとは別に設定します（メインで割り当て済みの表情から選びます）。

共通のオプション:

- **行 / 列**: グリッドの大きさ。
- **見つめて確定 (ms)**: 選んだタイルを見つめ続けると、表情なしで実行します（0 で表情でのみ実行）。
- **まばたきを無視 (ms)**
- **ページ送りボタンを表示**
- **カラー設定**: 背景・強調表示などの色と背景の透過度（3 つのツールで共通）。

#### 視線ランチャー

ポインタをその場で固定し、アイコンのグリッドを表示します。見つめて選んだアイテムを実行します。前面のアプリごとに項目を変えることもできます（**アプリ別アイテム**: 共通アイテムは全アプリで有効、アプリ別アイテムはそのアプリが前面の時に優先）。

表情割り当て: **決定 / 戻る / 終了 / 設定**（設定は、見ているセルの登録画面を開きます）。

アイテムの種類:

- **キー / マウス / マクロ**: キー操作やマウス操作を 1 行ずつ書き、上から順に実行します。右側のボタンやプリセット（コピー、貼り付け、書式なしで貼り付け、元に戻す、検索、保存、最大化、最小化、ウィンドウを閉じる、スクリーンショット、ホイール、首振りホイールモード、ドラッグ、長押し、スワイプ など）で行を追加できます。
  - `key ctrl+c`: キーを押す（+ で同時押し。例: `ctrl+shift+s`、`win+up`、`alt+f4`、`enter`、`esc`、`f5`）
  - `text こんにちは`: 文字を入力（クリップボード経由で貼り付けるため、クリップボードの内容は置き換わります）
  - `wait 500`: 指定ミリ秒待つ
  - `mouse left / right / middle / double`: 今のポインタの位置でクリック
  - `wheel up 3`: ホイールを回す（up / down / left / right と回数）
  - `drag left`: ボタンを押したままにし、次のクリックで離す
  - `hold left 800`: その場で指定ミリ秒長押し
  - `swipe ↑ medium`: 押したまま指定方向へ動かして離し、元の位置に戻る（small / medium / large = 画面の高さの 10 / 25 / 45%、または px の数値）
  - `wheelmode vh / hv`: 首振りホイールモードを開始
- **ファイルを開く**: アプリ、文書、フォルダなどを開きます（引数も指定可能）。
- **サブランチャー**: 別のページ（入れ子のランチャー）を開きます。
- **拡張機能**: クリップボード履歴やタスクスイッチャーを開きます。
- **視線キャリブレーション / サブモニター切替 / 戻る**

アイコンは自動、ライブラリから選択、画像ファイルから選択できます。ランチャーのオプション画面は、**独立したウィンドウで開く** こともできます。**管理・並び替え** で、複数選択、入れ替え、挿入、空白の挿入、削除ができます。

#### 視線クリップボード履歴

コピーしたテキストを記録し、視線で選んで前面のアプリに貼り付けます。よく使うものはピン留めできます。

- オプション: **クリップボード記録（監視開始）**、**アプリ開始時に履歴クリア**、**保存数（0 で無制限）**、**今すぐクリア**、**管理・ピン留め**（検索、ピン留め・解除、削除）、**ピン留め一覧ボタンを表示**
- 表情割り当て: 決定（貼り付け）/ 進む / 戻る / ピン留め / リスト切替（履歴 ⇔ ピン留め）/ 削除 / 終了

#### 視線タスクスイッチャー

開いているウィンドウをアイコン付きのグリッドで表示し、視線で選んで切り替えます（視線で Alt+Tab）。

- オプション: **切り替えたウィンドウにポインタを移動**（初期値オフ。オンにするとウィンドウの中央へ移動）、**非表示にするタスクを選択**（プロセス名やウィンドウ タイトルで一覧から除外。タイトルは完全一致で、ワイルドカード `*` `?` 使用可。実行中のプロセスから選択も可能）
- 表情割り当て: 決定（切り替え）/ 進む / 戻る / 閉じる（選んだウィンドウを閉じる）/ 終了

### ブックマーク

「マウス」「拡張機能」ページで ☆ を付けた機能だけを集めて表示します。よく調整する設定を 1 か所にまとめられます。

### 視線キャリブレーション

左メニューの「視線キャリブレーション」から実行します。画面に 16 個（または 8 個、下記参照）の緑の点が順番に表示されるので、表情はニュートラルのまま、それぞれを見つめます。点は 1 個あたり 2 秒で、だんだん小さくなります。Esc でキャンセルできます。

**詳細設定 → キャリブレーション → 点の数 → 8点** にすると、約 36 秒かかるところが約 20 秒で終わります。4×4 の点を市松模様に 1 つおきに使います。実際のキャリブレーションのデータで試したところ、精度は 16 点とほぼ同じでした。ただし点が少ないぶん、まばたきや目をそらしたなどで 1 点うまく見られなかったときの影響は大きくなります。8 点で合わないと感じたら、やり直すか 16 点を使ってください。視線がずれてきたと感じたら、こまめに再キャリブレーションしてください。座る位置やカメラの位置を変えた後も再キャリブレーションをおすすめします。

### 詳細設定

- **ジェスチャー感度 → 全体の感度**: すべての表情の値にかける倍率。大きな表情でも反応しない場合は上げ、わずかな動きで誤反応する場合は下げます。
- **サブモニター**: 透過率と拡大率。
- **スタートアップ**（完全版）
  - **サインイン時（ログイン画面等で起動）**: Windows のサインイン画面で、スクリーンキーボードでの入力を目的とした超軽量版を起動します。使えるのはマウス操作、視線ジャンプ、視線移動のみで、アニメーションは描画しません。画面上部に「顔操作 オン / オフ」「顔が見えません」の状態を表示します。
  - **サインイン後（デスクトップ、UAC 画面等で起動）**: サインイン後に自動で起動します。UAC の確認画面でも軽量版が起動して操作できます。
  - 変更時に Windows が許可を求めた場合は「はい」を選びます。
- **起動とウィンドウ**: **起動時のページ**（ホーム / 最後に開いていたページ）、**多重起動を許可**（通常は不要。カメラを取り合うため不安定になります）。
- **キャリブレーション**: **実行前に確認する**、**点の数**（16点 / 8点（約20秒））。
- **自動復旧**: エラーが起きたときに、操作不能にならないよう自動で再起動を試みます。設定が壊れていた場合は過去のバックアップ（毎日自動で作成）から復元して再起動します。顔操作がオンの間に、カメラの信号が途切れたり顔が見つからない状態が **閾値（秒）** 続いた場合は、カメラと顔検出を作り直します。
- **言語**: 日本語 / 英語（再起動後に反映）。
- **更新 → 更新を通知する**
- **GazeFaceについて**: バージョン、版（Full Edition / Standard Edition）などの情報。

### 終了

ウィンドウを閉じると確認画面が出て、「はい」で GazeFace を終了します。誤ってウィンドウを閉じても、すぐには終了しません。

## よくある質問

**Q. 視線だけで操作できますか？**
A. 視線はポインタを大まかな場所へ運ぶ用途（視線ジャンプ、視線移動、グリッドの選択）に使います。細かい位置合わせはヘッドトラッキングで行い、クリックは表情で行います。

**Q. 特別なカメラやアイトラッカーは必要ですか？**
A. 不要です。一般的な Web カメラ（720p、30 fps 以上）で動きます。

**Q. 顔が検出されません。**
A. 顔が正面から映るようにカメラを置き、真っ暗な部屋や逆光・明るすぎる場所を避けてください。他のアプリがカメラを使っていると使えません。

**Q. 管理者権限のアプリや UAC の画面で操作できません。**
A. 通常版の制限です。完全版をインストールするか、手動で署名してください。

**Q. 更新後にカメラの使用許可を求められました。**
A. 署名者が変わると、一部の Windows では許可を聞き直されます。完全版は同じ証明書を使い回すため通常は起きませんが、通常版から手動署名した場合などに起こります。

**Q. 料金はかかりますか？**
A. 無料です。Apache License 2.0 のオープンソースです。

**Q. 医療機器ですか？**
A. いいえ。医療用途を意図したものではありません。

## プライバシー

- カメラ映像はパソコンの中だけで処理し、保存も外部への送信もしません。
- 顔のランドマーク（目・鼻・口などの位置）を検出しますが、顔認証や個人の識別は行いません。
- 設定とログは `%LOCALAPPDATA%\GazeFace` に保存されます。サインイン画面用の軽量版の設定は `C:\ProgramData\GazeFace\signin` に保存されます。
- 外部との通信は、更新の確認とダウンロード（GitHub）のみです。

## ソースからのビルド

Python 3.12（64 ビット）を使います。

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
.venv\Scripts\python run_app.py
```

配布用の実行ファイルは PyInstaller で作成します。

```bash
.venv\Scripts\pyinstaller build.spec --noconfirm
```

初回起動時は `configs_template` の内容が設定の初期値になります。
